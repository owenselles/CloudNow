## Message 1 — Project and installation

# Frequently Asked Questions

## What is CloudNow?

CloudNow is an open-source, native Apple TV client for accessing GeForce NOW.

## Is this an official NVIDIA app or Discord server?

No. CloudNow is independent from NVIDIA. This Discord server is community-run
unless the upstream repository owner explicitly approves it as official and
links it from the repository.

## Where can I install CloudNow?

There is no App Store release. Current repository-documented routes are:

- TestFlight
- A release IPA
- Building from source

Use https://github.com/owenselles/CloudNow#installation and do not trust an App
Store listing or download merely because it uses the CloudNow name or artwork.

## What hardware and software do I need?

Check the current requirements in the repository README. Apple TV, tvOS, Xcode,
and account requirements can change as the project develops.

## Do I need a GeForce NOW account?

Yes. CloudNow does not provide an account, subscription, game ownership, or
service access.

## Message 2 — Accounts and help

## Can community staff fix my NVIDIA account or billing?

No. Account recovery, subscriptions, billing, regional availability, bans,
queues, and service-side problems must go through NVIDIA's official support.

## Can staff log in for me?

No. Staff will never ask for a password, Apple ID, login PIN, authentication
code, token, cookie, or QR code.

## Is CloudNow's QR sign-in legitimate?

Yes, CloudNow has a legitimate QR-based sign-in flow. The QR code is sensitive
and must not be shared, posted, or shown while streaming your screen.

## Where do I ask for help?

Create one post per problem in `#help`, select the closest forum tag, and fill
in the support template.

## Which CloudNow version should I provide?

Provide the release tag, TestFlight build number, or commit SHA. “Latest” is
ambiguous and makes reports harder to compare.

## Where do I report a bug?

Start in `#help` if diagnosis is incomplete. Once the problem is reproducible,
create or join a GitHub issue and link the support post.

## Message 3 — Features, logs, and security

## Where do I request a feature?

Discuss it in `#feature-discussion` and search GitHub before opening a new
issue. Discussion, reactions, and issues are not implementation commitments or
release dates.

## Can I upload logs or screenshots?

Only after reviewing and redacting them. Remove personal data, email addresses,
account identifiers, tokens, authentication headers, cookies, PINs, QR codes,
full IP addresses, private URLs, keys, and certificates.

## Are forks and modified builds allowed?

They may be discussed when clearly identified as unofficial and linked
transparently. Community support may be limited. Staff may remove suspicious
binaries or misleading distribution links.

## How do I report a security vulnerability?

Do not post it in Discord. Use GitHub private vulnerability reporting:

https://github.com/owenselles/CloudNow/security/advisories/new

Include enough detail to reproduce the issue without using real user
credentials. GitHub private vulnerability reporting is the canonical route.

## How do I appeal a moderation action?

Use the private appeal method stated in `#rules`.
