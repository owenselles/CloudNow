# `#known-issues`

## Channel description

Read-only pointers to confirmed CloudNow problems and their current tracking
status. For individual diagnosis, create a post in `#help`.

## Starter message

# Known issues

No community-wide issue is currently listed in this managed message. This does
not mean CloudNow has no bugs, and this message is not a substitute for the
repository's live issue tracker.

Use these sources for current status:

- Open issues: https://github.com/owenselles/CloudNow/issues
- Releases and release notes: https://github.com/owenselles/CloudNow/releases
- Installation and current requirements:
  https://github.com/owenselles/CloudNow#installation

If you encounter a problem:

1. Search `#known-issues`, `#faq`, existing `#help` posts, and GitHub issues.
2. If diagnosis is incomplete, create one post in `#help`, choose the closest
   tag, and fill in the support template.
3. If the problem is reproducible and appears to be a CloudNow defect, create
   or join a GitHub issue and link the relevant help post.

Never publish credentials, authentication data, login PINs, QR codes, personal
data, or unredacted logs. Report suspected vulnerabilities privately at
https://github.com/owenselles/CloudNow/security/advisories/new, not in Discord.
