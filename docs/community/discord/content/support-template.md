# `#help` Forum

## Channel description

Get community help installing, configuring, or using CloudNow. Search first,
then create one post per problem and complete the support template. Never post
credentials, tokens, login QR codes, personal data, or unredacted logs.

## Forum guidelines

1. Use a descriptive title, such as
   `[HDR] Stream falls back to SDR on LG C3`.
2. Search `#faq`, `#support-resources`, existing forum posts, and GitHub issues.
3. Keep one problem in each post and use the closest forum tag.
4. Include a release tag, TestFlight build number, or commit SHA; Apple TV
   model; tvOS version; installation route; and reproduction steps.
5. Redact attachments. CloudNow's QR login is legitimate, but the QR code,
   authentication data, full IP addresses, and personal data must not be
   shared.
6. Add the **Solved** tag when a solution works.
7. Confirmed software defects may move to GitHub for tracking.
8. Do not report vulnerabilities here. Use
   https://github.com/owenselles/CloudNow/security/advisories/new.

## Starter message

# CloudNow Support Resources

## Install or update

CloudNow has no App Store release. Use a repository-documented route:
TestFlight, a release IPA, or a source build.

- Installation: https://github.com/owenselles/CloudNow#installation
- Releases: https://github.com/owenselles/CloudNow/releases
- Current requirements: https://github.com/owenselles/CloudNow#requirements

## Before opening a help post

1. Record the release tag, TestFlight build number, or commit SHA.
2. Confirm your Apple TV model and tvOS version meet the current README
   requirements.
3. Update when practical, restart CloudNow and Apple TV, then reproduce once.
4. Note the exact error and the smallest reliable reproduction sequence.
5. Redact screenshots and logs.
6. Search `#faq`, `#help`, and GitHub issues.

Never share credentials, authentication data, login PINs, or QR codes. Report a
suspected vulnerability privately at
https://github.com/owenselles/CloudNow/security/advisories/new, not in Discord.
