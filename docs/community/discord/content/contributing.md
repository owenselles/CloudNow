## Starter message

# Contributing to CloudNow

Contributions to code, tests, documentation, diagnostics, and localization are
welcome.

## Before starting

1. Read the repository README.
2. Search existing issues and pull requests.
3. Discuss significant architecture or behavior changes before building them.
4. Keep each pull request focused on one logical change.
5. Never use or commit credentials, production tokens, private service data, or
   personal data.

## Before opening a pull request

- Follow the development and testing instructions in the README.
- Use the exact SwiftFormat and SwiftLint versions pinned in the README's
  **Linting** section.
- Run the documented non-mutating format and lint checks.
- Run relevant tests.
- Anonymize fixtures, logs, JSON, SDP, recordings, and binary samples.

Explain what changed, why it is needed, how it was tested, tested device and
tvOS versions, known limitations, related issues, and UI evidence when
relevant.

Repository: https://github.com/owenselles/CloudNow  
Issues: https://github.com/owenselles/CloudNow/issues  
Pull requests: https://github.com/owenselles/CloudNow/pulls

Final review, approval, and merge decisions remain on GitHub.
