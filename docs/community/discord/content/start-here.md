## Message 1

# Welcome to the CloudNow Community

This is a community-run space for CloudNow users and contributors. CloudNow is
an independent, open-source GeForce NOW client for Apple TV. It is not
affiliated with, endorsed by, or sponsored by NVIDIA.

Use this server to:

- Get installation and troubleshooting help.
- Discuss streaming, HDR, networking, audio, and controllers.
- Follow project releases and testing.
- Discuss features and development.
- Contribute code, documentation, testing, or localization.

Start by reading `#rules`. Then choose channels and notification roles in
**Channels & Roles**.

## Message 2

## Find what you need

- Help: create one post per problem in `#help`.
- Guides and common fixes: read `#support-resources` and `#faq`.
- Feature ideas: discuss them in `#feature-discussion`.
- Development: use `#development`; final project decisions stay on GitHub.
- Repository: https://github.com/owenselles/CloudNow
- Installation: https://github.com/owenselles/CloudNow#installation
- Releases: https://github.com/owenselles/CloudNow/releases
- Issues: https://github.com/owenselles/CloudNow/issues

There is no CloudNow App Store release. Current repository-documented routes
are TestFlight, a release IPA, or building from source.

## Message 3

## Protect your account

CloudNow uses a legitimate QR-based sign-in flow. A login QR code is still
sensitive: anyone who receives it may be able to access your session. Staff
will never ask for your password, Apple ID, NVIDIA credentials, authentication
code, token, cookie, login PIN, or QR code.

Do not post a suspected vulnerability in Discord. Use GitHub private
vulnerability reporting:

https://github.com/owenselles/CloudNow/security/advisories/new

GitHub private vulnerability reporting is the canonical route. Discord's
private `#security-response` channel is for staff coordination after a report
or an accidental exposure; it is not a vulnerability intake route.
