# `#feature-discussion`

## Channel description

Discuss potential CloudNow features and improvements before creating a formal
GitHub issue.

## Starter message

# Feature idea

Use this outline when starting a focused feature discussion:

**Problem or limitation:**

**Proposed behaviour:**

**Who would benefit:**

**Example use case:**

**Alternatives or workarounds:**

**Possible drawbacks:**

**Relevant platform or device constraints:**

**Would you be interested in testing or contributing?**

Search existing Discord discussions and GitHub issues before posting. Community
interest helps maintainers understand demand, but discussion is not a commitment
or release date.
